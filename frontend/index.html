04 / The idea

What is Three Address Code?

TAC is an intermediate representation used by compilers. Each instruction generally contains at most three addresses: a destination and one or two operands.

By breaking a complex expression into small, ordered steps, the compiler can optimize and translate it into machine code more easily.
